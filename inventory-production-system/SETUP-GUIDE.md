## 📋 תהליך ההתקנה צעד אחרי צעד

### 1️⃣ יצור גוגל שיט חדש

```
https://sheets.google.com
↓
לחץ על "+" 
↓
שם את הגיליון: "תוכנית ייצור - [שם החברה]"
```

### 2️⃣ הוסף Google Apps Script

**בגוגל שיט:**
```
Extensions 
  ↓
Apps Script
```

**בחלון Apps Script:**
```
1. מחק את הקוד הקיים (Hello, world!)
2. העתק את הקוד המלא מ- apps-script.js
3. Save (Ctrl+S)
4. אם תשאל להרשאה - אתה מרשה ל-Apps Script לערוך את הגיליון
5. סגור את תאבץ Apps Script
```

### 3️⃣ הפעל ההוראה

**בחזרה לגוגל שיט:**
```
כעבור שנייה, בחלק העליון תראה תפריט חדש:
📊 תוכנית ייצור
  ├─ 📥 יבא דוח מלאי
  ├─ 🔄 עדכן חישובים
  ├─ 🖨️ הדפס תוכנית
```

### 4️⃣ אתחול הגיליונות

**בתפריט:**
```
📊 תוכנית ייצור
  ↓
🔄 עדכן חישובים
```

זה ייצור שני גיליונות באופן אוטומטי:
- "דוח מלאי" - כאן תדביק את הדוח היומי
- "תוכנית ייצור" - כאן תבנה את התוכנית

**CSV (רשימה מופרדת בפסיקים):**

001,מוצר A,50,100,300
002,מוצר B,80,150,400

קוד    שם מוצר    מלאי קיים    מינימום    מקסימום
001    מוצר A    50           100         300

## ✨ הגדרה מתקדמת

### שינוי נוסחת החישוב

אם אתה רוצה נוסחה שונה ל"צריך לייצר", בגיליון "דוח מלאי":

**בעמודה F (צריך לייצר), בשורה 2:**
```
=IF(AND(C2<>"", D2<>""), MAX(0, E2-C2), "")
```

**פירוש:**
- `E2` = מלאי מקסימום
- `C2` = מלאי קיים
- `MAX(0, E2-C2)` = הכמות הנדרשת (לא פחות מ-0)

### שינוי ימי השבוע

בגיליון "תוכנית ייצור", בשורה 3:
```
ראשון | שני | שלישי | רביעי | חמישי | שישי | סה״כ שבוע
```

אתה יכול להחליף לימי שבוע אחרים או להוסיף ימים נוספים.

## 🔐 הרשאות וביטחון

כשאתה משתמש ב-Apps Script בפעם הראשונה:
- Google יבקש אישור
- לחץ "Review permissions"
- בחר את החשבון שלך
- לחץ "Allow"

זה בטוח - Apps Script יכול רק:
- לקרוא את הגיליון שלך
- לעדכן את הגיליון שלך
- **לא יכול** לשלוח אימיילים או לגשת לקבצים אחרים

---

## 🐛 פתרון בעיות

### בעיה: התפריט "📊 תוכנית ייצור" לא מופיע

**פתרון:**
1. Refresh את הדף (F5 או Cmd+R)
2. אם עדיין לא מופיע:
   - Extensions > Apps Script
   - בדוק אם הקוד שלך נשמר
   - אם לא - לחץ Save

### בעיה: "Permission denied" בעת יבוא

**פתרון:**
1. בתוך Apps Script, לחץ על "Run" (▶️)
2. בחר "importInventoryData"
3. אתה מאשר הרשאות
4. כעת יעבוד

### בעיה: הנוסחאות לא מחשבות

**פתרון:**
1. בדוק שהעמודות הנכונות:
   - עמודה C = מלאי קיים
   - עמודה D = מינימום
   - עמודה E = מקסימום
2. אם לא - הזז את הנתונים למקום הנכון

## 💡 עצות להצלחה

1. **שמור מקום שקט לגיליון** - בנה קובץ עם השם "תוכנית ייצור" כדי שתוכל למצוא אותו בקלות

2. **שכפל לתוכנית בחודשים אחרים** - File > Make a copy, כך יישמרו כל התוכניות

3. **אם אתה רוצה נתונים היסטוריים** - שמור את הנתונים בגיליון נפרד בשם "ארכיון"
