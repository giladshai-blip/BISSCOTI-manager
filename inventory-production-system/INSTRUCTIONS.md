# 📖 הוראות שימוש - מערכת תוכנית ייצור שבועית

## 🎯 מטרת המערכת

מערכת זו מאפשרת לך:
- ✅ לייבא דוח מלאי יומי
- ✅ לחשב אוטומטית את כמות הייצור הנדרשת (על סמך מלאי מינימום ומקסימום)
- ✅ לבנות תוכנית ייצור שבועית (ראשון עד שישי)
- ✅ לשבץ כמויות בכל יום
- ✅ להדפיס תוכנית מוכנה לצוות הייצור

---

## 🚀 שלב 1: הגדרה ראשונית

### צור גוגל שיט חדש

1. זהק לכאן: **https://sheets.google.com**
2. לחץ על **"+"** (גיליון חדש)
3. שם את הגיליון: **"תוכנית ייצור"**

### הוסף את Google Apps Script

1. בגיליון שיצרת, לך ל- **"Extensions" > "Apps Script"**
2. מחק את הקוד הקיים
3. העתק את כל הקוד מ- `apps-script.js`
4. לחץ **"Save"** (Ctrl+S או Cmd+S)
5. אתה יכול לסגור את תאבץ Apps Script

### הפעל ההוראה

כשתחזור לגוגל שיט, תראה בתפריט חדש בחלק העליון: **📊 תוכנית ייצור**

---

## 📥 שלב 2: יבוא דוח מלאי יומי

### כל יום:

1. **הורד את דוח המלאי שלך** (מהמערכת WMS שלך)
2. **עתיד לכן בגוגל שיט** או **העתק את הנתונים לAtipboard**
3. בתפריט העליון, לחץ **📊 תוכנית ייצור > 📥 יבא דוח מלאי**
4. בחלון שנפתח:
   - **העתק את דוח המלאי שלך** (CSV או טאב מופרד)
   - הדבק לתיבת הטקסט
   - לחץ **"יבא נתונים"**

### מה יקרה:
- ✅ הנתונים יוכנסו לגיליון "דוח מלאי"
- ✅ יחושבו אוטומטית כמויות הייצור
- ✅ תוכנית הייצור תתעדכן עם מוצרים שצריכים ייצור

---

## 📊 שלב 3: בנייה תוכנית ייצור שבועית

### גיליון "תוכנית ייצור"

אחרי יבוא הנתונים, בגיליון השני תראה:

| מוצר | ראשון | שני | שלישי | רביעי | חמישי | שישי | סה״כ |
|------|-------|-----|-------|-------|-------|------|------|
| מוצר A (250) | | | | | | | |
| מוצר B (320) | | | | | | | |
| מוצר C (220) | | | | | | | |

### איך למלא:

1. בכל תא ריק, הכנס את **כמות הייצור ליום זה**
2. עמודת **"סה״כ"** תחשב בעצמה את סכום השבוע
3. המספר בסוגריים = סה"כ הכמות שצריך לייצר

**טיפ:** קרא מחדש כל יום בבוקר כדי לקבל נתונים מעודכנים!

---

## 🖨️ שלב 4: הדפסה

### הדפס את תוכנית הייצור:

1. בגיליון "תוכנית ייצור" - **Ctrl+P** (או **Cmd+P** ב-Mac)
2. בחר **"עמוד A4"** או **"A3"** (תלוי בגודל הטבלה)
3. הדפס!

**או:**
- בתפריט העליון: **📊 תוכנית ייצור > 🖨️ הדפס תוכנית**

---

## 💾 מבנה הנתונים

### גיליון 1: "דוח מלאי"
```
קוד | שם מוצר | מלאי קיים | מינימום | מקסימום | צריך לייצר
001 | מוצר A  | 50        | 100     | 300      | 250
```

**חישוב אוטומטי:**
```
צריך לייצר = MAX(0, מקסימום - מלאי קיים)
```

### גיליון 2: "תוכנית ייצור"
- מוצרים שבהם `צריך לייצר > 0` מופיעים בתוכנית
- אתה ממלא כמויות לכל יום
- הסה״כ מחושב אוטומטית

## ⚙️ טיפים שימושיים

### חיתוך אתי בעמודות:
- גרור את קו ההפרדה בין שתי עמודות בשדה הכותרת

### הוסף מוצרים:
- כל מוצר שתוסיף לדוח המלאי יופיע בתוכנית

- File > Version history > Save new version
- כך תוכל לחזור לתוכניות קודמות
