# מערכת תוכנית ייצור שבועית

מערכת לניהול תוכנית ייצור על סמך דוח מלאי יומי עם מלאי מינימום ומקסימום.

## 📋 תכונות

- ✅ ייבוא דוח מלאי יומי
- ✅ חישוב אוטומטי של כמות ייצור נדרשת (הפרש בין מקסימום למלאי קיים)
- ✅ תוכנית ייצור שבועית (ראשון - שישי)
- ✅ שיבוץ כמויות לכל יום
- ✅ עיצוב מוכן להדפסה

## 🚀 איך להשתמש

### 1. יצירת גוגל שיט
1. פתח https://sheets.google.com
2. צור גיליון חדש
3. העתק את התבנית מהקובץ `production-plan-template.html`

### 2. הוספת Google Apps Script
1. בתוך הגוגל שיט, לך ל- "Extensions" > "Apps Script"
2. העתק את הקוד מ- `apps-script.js`
3. שמור וברור

### 3. ייבוא דוח מלאי
1. בגיליון "דוח מלאי" - דביק את הדוח היומי שלך
2. הנוסחאות יחשבו בעצמן את הכמות הנדרשת

### 4. בנייה תוכנית ייצור
1. כנס לגיליון "תוכנית ייצור"
2. שבץ את הכמויות בכל יום
3. הדפס או צפה בתוכנית

## 📊 מבנה הקבצים

```
inventory-production-system/
├── README.md (קובץ זה)
├── apps-script.js (קוד Google Apps Script)
├── production-plan-template.html (תבנית HTML)
└── data-sample.csv (דוגמה של דוח מלאי)
```
