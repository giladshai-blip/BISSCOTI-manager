# ⚡ התחלה מהירה (5 דקות)

## סיכום קצר ביותר

### 1. פתח https://sheets.google.com
### 2. בנה גיליון חדש
### 3. בחר Extensions → Apps Script
### 4. העתק את הקוד מ- `apps-script.js`
### 5. Save (Ctrl+S)
### 6. חזור לגוגל שיט
### 7. כעת יש לך תפריט: 📊 תוכנית ייצור

---

## בעזרת התפריט החדש:

```
📊 תוכנית ייצור
│
├─ 📥 יבא דוח מלאי    ← דביק את הדוח היומי שלך
├─ 🔄 עדכן חישובים   ← יצור גיליונות בעצמאי
├─ 🖨️ הדפס תוכנית    ← הדפס את התוכנית
```

---

## כל יום:

```
1. הורד דוח מלאי
2. 📥 יבא דוח מלאי → הדבק
3. מלא כמויות בימים
4. 🖨️ הדפס תוכנית
5. תן לצוות הייצור
```
